# Roadmap

Future roadmap entries should describe new planned slices only after the stable
product or control-plane contract is clear enough to bound the work. Completed
execution history is available through git history; unresolved follow-up belongs
in [Deferred Work](./deferred-work.md).

This roadmap is only for future sequencing notes that are not already
represented by an active plan.

## Sequencing Rule

Do not widen runtime, source, destination, or docs-control contracts through
plan prose alone. If a later slice needs a new durable rule, that rule belongs in
the compact root docs first.
